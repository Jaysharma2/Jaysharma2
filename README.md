- Built **CI/CD pipelines with GitHub Actions** to test, build, tag, and push images to **Amazon ECR** and deploy versioned releases to EKS/ECS.

## 🎓 Research: Master's Thesis

**Prompt Learning for Zero-Shot Domain Adaptation in Vision-Language Models with Stable Diffusion-Based Synthetic Data Generation**
*IIT Bombay · Advisors: Prof. Subhasis Chaudhuri & Prof. Biplab Banerjee · May 2024 – Jul 2025*

- **Goal:** improve zero-shot domain adaptation for **remote sensing scene classification** in VLMs through prompt learning.
- **Approach:** generate a synthetic source dataset with **ControlNet + Stable Diffusion**, then apply **Visual Attention Parameterized Prompt Learning** in **CLIP** to improve cross-domain class predictions.
